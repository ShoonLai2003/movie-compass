# Movie Compass

## サイト概要

### サイトテーマ
映画のレビューを投稿・共有し、おすすめの映画を見つけることができるレビューサイトです。

### テーマを選んだ理由
私は映画を見ることが好きですが、新しい映画を探すときに、どの作品が自分に合っているのか分からず、迷うことがよくあります。映画の評価だけでなく、実際に視聴した人の感想やレビューを参考にして作品を選びたいと思うことが多くありました。

また、私はインド映画をよく見ていますが、日本に来てからは日本映画やアニメ映画を見る機会も増えました。しかし、作品数が多いため、どの作品から見ればよいのか迷うこともありました。同じように、映画選びに悩んでいる人や、自分の感想を他の人と共有したいと考える人も多いと思います。

そこで、ユーザー同士がレビューを投稿・共有し、おすすめの映画を見つけられるレビューサイトを制作することで、映画選びの悩みを解決できるサービスを作りたいと考え、このテーマを選びました。

### ターゲットユーザ
- 映画選びに迷っている人
- 映画の感想やレビューを共有したい人
- 他の人のレビューを参考に映画を選びたい人

### 主な利用シーン
- 新しい映画を探している時
- 映画を見終わった後にレビューを投稿したい時
- 他のユーザーのレビューを参考に映画を選びたい時
